# Tatada print assets

Reusable original vector pen drawings live in `icons/`: car, food, coffee, mountain, tree, bed, star, walk, suitcase, camera, plane and pencil. SVGs have transparent backgrounds and accessible titles. Their paths are shared with the sharp PDF drawings in `src/print/notebook.ts`.

The print family uses cream notebook paper, green pen headings, ruled writing space and a Tatada star footer. Journals use framed photos with tape accents; stays, packing lists and flight keepsakes have category-specific icons.

Bundled sample journal illustrations remain in `public/journal/`. They are illustrative artwork, not travelers' real photos. Actual journal printouts use the traveler's saved memories; missing photos do not create invented memories.
