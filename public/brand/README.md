# Wajo Fo icon

`wajo-fo.png` is Wajo's official icon for its Fo service, copied unmodified
from the icon Wajo publishes in the Fo MCP server's metadata
(`serverInfo.icons` of `wajo-fo` at https://mcp.api.wajo.ai/fo, served from
https://mcp.api.wajo.ai/icon.png, 512×512 PNG,
sha256 `e38a700c203cabe441ecd59cdf10a9242bd6dca41cae5ce861ecf4b774bb4249`,
retrieved 2026-10-17).

MCP clients use server icons to show which service they're talking to. Tatada
uses it only on the button that opens Fo-powered Magic, with "powered by Wajo
Fo" attribution. It is Wajo's mark, not Tatada's. If Wajo provides a brand kit
or a Fo-specific mark, replace this file and keep the attribution.
