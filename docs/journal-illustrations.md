# Sydney journal illustrations

Generated with the built-in image_gen tool on October 18, 2026. These are drawn sample memories, not photographs or records of an actual visit. No real faces or likenesses were used. The original generated PNGs remain in Codex's generated-images folder. The app uses optimized JPEGs:

- `public/journal/sydney-harbour-v1.jpg` — Sydney Harbour, two stick figures, ferry and landmarks.
- `public/journal/sydney-lunch-v1.jpg` — a shared fish-and-chips lunch, with tiny stick-figure doodles.

They appear only in the Sydney example journal and its exported PDF; destination discovery stays photo-free. Memories retain an allowlisted illustration identifier, so account exports include the reference without bloating the workspace with image data. User photos remain separate and are never replaced by these illustrations.
